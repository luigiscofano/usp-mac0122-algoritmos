# Procedência e reconstrução

Temas recuperados de conversas de outubro/novembro de 2023: E05 genes, E06 união de intervalos e T07 busca em A+A. Os fontes originais entregues não foram localizados. O código desta edição é uma reconstrução nova de 2026, com assistência de IA e testes reais.

A página pública da edição confirma o nome Princípios de Desenvolvimento de Algoritmos. A descrição anterior como Algoritmos e Estruturas de Dados era temática, não o título oficial recuperado.

As conversas de E06 divergem sobre stdin versus nome de arquivo. Esta edição aceita ambos e usa -v para listar componentes e gerar SVG. Usa um record Intervalo independente em vez do Interval1D exigido no exercício histórico. Elimina a dependência gráfica, mas não é uma submissão estritamente compatível com o avaliador antigo.

Os links históricos de E05 não forneceram os fontes nesta recuperação. O contrato dos genes está, portanto, explicitado nesta edição: ATG inicial, primeiro TAA/TAG/TGA no mesmo quadro, stop incluído, sem stop interno. A ordem é a dos inícios, sem alegação de igualdade byte a byte à saída de um fonte não recuperado.

## Extensão nova em C

O módulo Collatz desta edição é uma implementação independente de estudo, sem copiar um fonte histórico como se tivesse sido autenticado. A extração textual do relatório de 2022 está em acervo/, publicada com autorização do autor. As imagens e o fonte original não foram extraídos; o programa em C11 continua identificado como novo.
